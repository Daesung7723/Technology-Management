# Technology-Management

기술경영·기술사업화 교재의 공개 저장소입니다. 단국대학교 「기술과경영」 강의를 위해 집필한 교재 v3.0(5부 46장)과 실습 양식을 원천으로 하며, 대학 강의와 예비 창업자 교육에 함께 활용할 수 있도록 정제해 게시합니다.
저자: 김대성

> **게시 준비 중** — 본문·양식은 검토와 보완을 거쳐 한 번에 게시합니다. 아래 구성표의 "예정" 항목은 게시 시점에 채워집니다.

## 이 교재에 관하여

이 교재는 기술경영·기술사업화의 이론과 실무 도구를 46개 장으로 정리한 **기술과경영 교재 v3.0**입니다. 기존 교재 v2.0(CH 1~10)의 개정판이 아니라, v2.0의 이론 골격을 원천으로 삼아 집필된 기술사업화 이론 원고 46편을 교재 체계로 전면 재구성한 신규 판입니다.

- **대상 독자**: 기술경영·기술사업화 과목을 수강하는 학부생과, 기술 기반 창업을 준비하는 예비 창업자·초기 창업팀을 함께 독자로 합니다. 경영·경제·제도 분야의 사전 지식을 전제하지 않으며, 경영·제도 용어는 각 장의 첫 등장에서 풀이합니다.
- **구성 원리**: 46개 장은 기술경영의 5프로세스(식별·선택·획득·활용·보호)를 펼쳐 놓은 구조입니다. 상세한 안내는 [III-1장](Chapters/III-01_기술경영_개론.md) "이 교재의 구성 원리" 절에 있습니다.
- **사업계획과의 연결**: 각 장의 말미에 "사업계획에서의 위치" 절을 두어 그 장의 내용이 사업계획의 어느 구성 요소에 답하는지 정리했습니다. 초기 팀·창업자 관점의 적용 방법은 "사업계획에 적용하기" 절이 담당합니다(22개 장).
- **참조 표기**: 본문의 `(→ X-N장)`은 해당 장으로의 링크입니다. 각 장 말미의 "연결 장" 블록에 선행·후행·참조 장이 정리되어 있습니다.
- **읽는 순서**: 순서대로 통독할 수도 있고, 필요한 장만 참조할 수도 있습니다. 강의 수강생은 [강의 대응표](Courses/DKU_기술과경영/README.md)의 해당 주차 장을 우선 읽으면 됩니다.
