## Section 2. PEST 분석

아래 표에 우리 팀 기술 분야를 기준으로 P·E·S·T 각 축의 요인을 분석하세요.
각 요인은 반드시 **기회(O) 또는 위협(T)**으로 분류하고, **영향도**와 **긴급도**를 함께 표기합니다.

| 축 | 요인 (구체적으로 작성) | O / T | 영향도 | 긴급도 | 우리 사업과의 연결 |
|---|---|---|---|---|---|
| **P** | | | | | |
| **P** | | | | | |
| **E** | | | | | |
| **E** | | | | | |
| **S** | | | | | |
| **S** | | | | | |
| **T** | | | | | |
| **T** | | | | | |

> **O** = 기회(Opportunity) / **T** = 위협(Threat)
> **영향도** = High / Medium / Low
> **긴급도** = 단기(1년 이내) / 중기(1~3년) / 장기(3년 이상)

**영향도 × 긴급도 결론** — 분석 결과를 한두 문장으로 정리해주세요.

> 고영향·단기 요인: ___개 | 고영향·중장기 요인: ___개
>
> 외부환경 평가: 기회 우세 / 위협 우세 / 균형 (하나에 동그라미)
