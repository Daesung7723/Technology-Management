## 작성 순서

1. **환경·산업 읽기** — I-04 기술 트렌드 리포트(I-01 체크리스트로 점검) → I-02 산업분석
2. **문제·가치 설계** — I-05 문제정의·아이디어 도출 → III-02 SWOT·TOWS와 I-07 가치제안 캔버스(순서 무관)
3. **사업화 설계** — II-01 기술 로드맵(이후 장을 학습하며 버전 갱신) → I-11 린 캔버스 → IV-06 Pitch Deck

양식 안의 `I-05 Part 1-1`과 같은 표기는 다른 양식의 해당 절을 가리킵니다. 원 양식은 단국대학교 「기술과경영」 강의의 팀 프로젝트용으로 만들어졌으며, 이 저장소에서는 학기·제출 요소를 제거하고 대응 장 번호를 부여해 게시합니다. 강의 주차와의 대응은 [Courses](../Courses/DKU_기술과경영/README.md)를 참조하십시오.
